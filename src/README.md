# src/

Kaynak kod dizini. **Şu an boş** — ilk kod buraya gelecek.

`AI_JURI.md` bölüm 2 ve 3'ün kanıt dizinidir. Özellikle bölüm 3 (X-Factor)
`src/<dosya>:<satır aralığı>` biçiminde **satır düzeyinde** referans ister;
kodu buna göre okunabilir ve stabil tutun.

## Yapılacak

- [ ] Teknoloji yığını seçildiğinde bu dosyayı gerçek modül açıklamasıyla değiştirin
- [ ] Bağımlılık dosyasını ekleyin (`requirements.txt` / `pyproject.toml` / `package.json`)
- [ ] Çalıştırma komutunu `AI_JURI.md` bölüm 4 ve `submission.json` → `calistirma.komut`
      alanına **aynı** şekilde yazın
- [ ] Sırları koddan değil `.env`'den okuyun; her yeni değişkeni `.env.example`'a ekleyin

> Bu dosya yalnızca dizini git'te tutmak için var (git boş dizin takip etmez).
> Gerçek kod geldiğinde silebilir veya modül dokümantasyonuna dönüştürebilirsiniz.
